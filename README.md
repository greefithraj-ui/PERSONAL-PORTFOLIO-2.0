# Greefith Raj P.G — Portfolio

Open index.html in a browser. Keep styles.css and motion.js alongside it. There is no installation or build step. The optional web fonts have local fallbacks.

The hero uses the original portrait in assets/portrait.jpg. An embedded transparent grayscale PNG in index.html removes the red studio background and retains soft hair edges. The five scene layers have independent pointer and scroll offsets, with a narrow tilt range on the portrait. The image and composition are visible before JavaScript runs. Pause motion and the operating system's reduced-motion preference both select the static composition.

Edit the stage, content and navigation in index.html, the lighting and typography in styles.css, and the movement in motion.js.
